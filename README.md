# ⚔️ Dangerous Dungeons

**Пошаговая тактическая стратегия в мире DnD**  
Unity | C# | Windows / macOS / Linux

---

## 📖 О проекте

**Dangerous Dungeons** — это пошаговая стратегия, вдохновлённая настольными играми вроде **Dungeons & Dragons**. Вы управляете отрядом героев, которые должны отражать волны врагов, пробираясь всё глубже в опасные подземелья.

Каждый ход требует стратегического мышления: атаковать, защищаться, использовать заклинания или подготовиться к следующей волне. Продуманная тактика — единственный путь к победе.

---

## 🎮 Геймплей

### Основные механики

- **Пошаговые сражения** — планируйте действия, а затем смотрите, как они выполняются
- **Волны врагов** — каждая следующая волна сильнее предыдущей
- **DnD-система бросков** — атаки основаны на кубиках
- **Тактическое позиционирование** — расположение отряда влияет на бой

## 🧙‍♂️ Герои

Выберите отряд из 3 героев. У каждого — уникальные способности и стиль игры.

| Имя | Роль | Описание |
|-------|------|----------|
| 🛡️ **Biv** | Танк | Броня, мощные удары, выдерживает тонны урона |
| 🏹 **Ashen** | ДД (дальник) | Высокий урон с дистанции|
| ⛑️ **BrightFire** | Хилер | Лечение команды |

## 🚀 Запуск и установка

- Клонируйте репозиторий
```bash
git clone https://github.com/Step1709/Dungerous_Dungeons.git
```
- Перейдите в папку проекта
- Откройте проект в Unity Hub
- Соберите проект через File → Build Settings
